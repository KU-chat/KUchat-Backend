### 🛠️ Tech Stack
- language - `Java 17`
- framework - `spring boot 3.2.3`
- DB - `H2 Database`, `Amazon RDS for MySQL`
- ORM - `Spring Data JPA`
- Deploy - `Github Actions`, `Docker`
- Logging - `Logback`
- API Docs - `SpringDoc Swagger`
